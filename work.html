Features shipped
  • Four production integrations. Calendly on OAuth, Fireflies and Fathom on API keys, plus a LinkedIn data pipeline.
  • In-chat connection cards. Connect a tool mid-conversation instead of hunting for a settings page.
  • Wix site import. Prompt engineering and the interface around it.
  • Multi-image template preview. Database schema through to the hover slideshow.
Internal systems
  • Daily API-key re-validation. Dead integration keys used to fail silently. A nightly job now finds them and fires a Slack alert, an email and an in-app prompt to reconnect.
  • LinkedIn vendor migration. Benchmarked providers, swapped ours out invisibly, then wired up usage billing with margin tracking and low-balance alerts.
